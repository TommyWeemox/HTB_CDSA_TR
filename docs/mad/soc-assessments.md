# SOC Assessments

## Objectif

Évaluer la capacité de détection d'un SOC et prioriser les améliorations.

## Concepts

- Mesurer la **couverture** par technique : visibilité (logs) + détection (règles) + qualité.
- Heatmap Navigator de couverture.
- Gap analysis : menace pertinente × couverture faible = priorité.
- Indicateurs : MTTD, MTTR, taux de faux positifs.

## Exercices

- [ ] Cartographier tes détections (`detections/`) sur Navigator
- [ ] Lister les 10 techniques prioritaires non couvertes

## À retenir

- Avoir des logs ≠ avoir une détection.
