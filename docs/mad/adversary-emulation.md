# Adversary Emulation

## Objectif

Planifier et exécuter une émulation d'adversaire pour valider les défenses.

## Concepts

- Plan d'émulation : renseignement → sélection des TTP → scénario → exécution → rapport.
- Outils : Caldera, Atomic Red Team, Invoke-AtomicRedTeam.
- Purple teaming : red et blue collaborent, boucle de feedback rapide.

## Exercices

- [ ] Écrire un plan d'émulation d'un groupe (5-8 techniques)
- [ ] Exécuter le plan dans le lab et noter ce qui est détecté ou non

## À retenir

- Le livrable est une **amélioration de détection**, pas une compromission.
