# ATT&CK Fundamentals

## Objectif

Maîtriser le vocabulaire et savoir naviguer dans ATT&CK.

## Concepts

- **Tactique** (le *pourquoi*), **technique** (le *comment*), **sous-technique**, **procédure** (implémentation réelle d'un groupe/logiciel).
- Matrices : Enterprise, Mobile, ICS.
- Objets : groupes, logiciels, campagnes, mitigations, data sources.
- **ATT&CK Navigator** : visualiser et superposer des couches (couverture, menace).

## Exercices

- [ ] Choisir un groupe, lister ses techniques, les exporter dans Navigator
- [ ] Pour 5 techniques, identifier les *data sources* nécessaires

## À retenir

- ATT&CK est un **langage commun**, pas une checklist exhaustive.
