# Threat Hunting & Detection Engineering

## Objectif

Utiliser ATT&CK pour guider hunts et création de détections.

## Concepts

- Hunt basé sur une technique : comprendre → émuler → observer les données → requête → tuner.
- Analytics robustes : cibler le **comportement** plutôt que l'outil.
- Voir [méthodologie de hunt](../hunting/methodology.md) et [cycle de vie](../detection-engineering/lifecycle.md).

## Exercices

- [ ] Choisir 3 techniques, produire hunt + règle Sigma pour chacune
- [ ] Tester avec Atomic Red Team ([tests](../detection-engineering/testing.md))

## À retenir

- Une détection se valide **en l'attaquant**.
