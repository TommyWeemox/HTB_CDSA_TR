# Cyber Threat Intelligence

## Objectif

Transformer un rapport de menace en techniques ATT&CK exploitables.

## Méthode de mapping

1. Lire le rapport, extraire les **comportements** (pas les IOC).
2. Pour chaque comportement, identifier tactique puis technique/sous-technique.
3. Justifier avec la preuve du rapport.
4. Prioriser selon la pertinence pour ton organisation.
5. Exporter vers une couche Navigator.

## Niveaux de CTI

Stratégique, opérationnel, tactique, technique.

## Exercices

- [ ] Mapper 3 rapports publics (DFIR Report, Mandiant, CISA)
- [ ] Comparer deux groupes sur Navigator

## À retenir

- Les **comportements** survivent plus longtemps que les IOC (pyramide de la douleur).
