# Examen CDSA

L'examen est un scénario pratique de type SOC : investigation sur une infrastructure simulée, avec un rapport à rendre.

!!! warning "À vérifier"
    Durée, format et critères exacts : consulter la page officielle de l'examen sur HTB.

## Stratégie

1. **Cadrer** : lire tout l'énoncé, lister les questions, noter les heures de départ.
2. **Chronologie** : bâtir une timeline dès les premiers indices (qui, quoi, quand, où).
3. **Pivoter** : IOC → hôte → utilisateur → processus parent → réseau.
4. **Capturer** : captures d'écran et requêtes au fur et à mesure.
5. **Rédiger** pendant l'investigation, pas après.

## Checklist avant l'examen

- [ ] Cheatsheets SPL / KQL à portée de main
- [ ] Event IDs Windows et Sysmon connus par cœur
- [ ] Template de rapport prêt ([templates](../resources/templates.md))
- [ ] 2 examens blancs chronométrés réalisés
- [ ] Environnement de capture d'écran testé
