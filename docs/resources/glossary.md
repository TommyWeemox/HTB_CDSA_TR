# Glossaire

| Terme | Définition |
|---|---|
| **IOC** | Indicator of Compromise : artefact observable (hash, IP, domaine) |
| **IOA** | Indicator of Attack : comportement indiquant une attaque en cours |
| **TTP** | Tactics, Techniques, Procedures |
| **SIEM** | Security Information and Event Management |
| **SOAR** | Security Orchestration, Automation and Response |
| **EDR / XDR** | Endpoint / Extended Detection and Response |
| **MTTD / MTTR** | Mean Time To Detect / Respond |
| **C2** | Command and Control |
| **LOLBin** | Binaire légitime détourné par un attaquant |
| **Beaconing** | Communication périodique d'un implant vers son C2 |
| **Purple team** | Collaboration red et blue pour améliorer les détections |
| **Detection-as-Code** | Gestion des détections comme du code (git, CI, tests) |
| **Pyramid of Pain** | Hiérarchie des indicateurs selon la difficulté de changement pour l'adversaire |
