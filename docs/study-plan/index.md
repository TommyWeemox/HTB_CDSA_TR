# Plan d'étude

## Objectifs

1. Réussir l'examen **HTB CDSA**.
2. Obtenir les badges **MITRE ATT&CK Defender** (MAD).
3. Produire un portfolio : détections Sigma, hunts documentés, home lab.

## Rythme conseillé

| Bloc | Durée | Contenu |
|---|---|---|
| Cours | 1 h | Module HTB ou cours MAD |
| Lab | 1 h | Reproduire, requêter, casser |
| Notes | 30 min | Note + cheatsheet + ID ATT&CK |
| Révision | 30 min | Relecture espacée (J+1, J+7, J+30) |

## Méthode

- **Active recall** : fermer la note, réécrire les requêtes de mémoire.
- **Un module = une détection** : chaque module finit par une règle ou un hunt dans `detections/` ou `hunts/`.
- **Examen blanc** : à partir de la semaine 9, faire des scénarios chronométrés.

Voir le [planning](12-weeks.md) et le [suivi](progress.md).
